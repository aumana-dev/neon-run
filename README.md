# Neon Run · Atrapa tu energía

Colección de minijuegos de reflejos para BE ONE Immersive Run (28 nov, Terrazas Lindora), con identidad visual de escenario inmersivo inspirada en kölbi.

Al entrar se puede elegir entre dos modos:

- **Neon Run:** atrapa los objetos de energía y evita obstáculos durante 25 segundos.
- **Pulso de señal:** toca cuando el indicador atraviesa la zona verde; la señal se acelera en cada nivel.

Ambos modos comparten puntos, racha, vidas y niveles. El escenario ilustrado está en `assets/activation-stage.svg`.
