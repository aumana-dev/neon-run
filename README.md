# BE-ONE GAME · Atrapa tu energía

Juego de reflejos para BE ONE Immersive Run (28 nov, Terrazas Lindora).

Un solo archivo: `index.html`. Sin dependencias ni build.

El juego no envía puntuaciones ni datos personales a un servidor. El récord se guarda solo en el almacenamiento local del navegador. El botón Compartir comparte únicamente el nombre del juego y su enlace público.
