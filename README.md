# Neon Run · Atrapa tu energía

Juego de reflejos para BE ONE Immersive Run (28 nov, Terrazas Lindora), con identidad visual de escenario inmersivo inspirada en kölbi.

La partida sigue activa: atrapa los objetos de energía, evita los obstáculos y suma puntos antes de que termine el tiempo. El escenario ilustrado está en `assets/activation-stage.svg`.
