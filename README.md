# BE-ONE × kölbi · Immersive Run

Colección de minijuegos de reflejos para BE-ONE × kölbi Immersive Run (28 nov, Terrazas Lindora), con identidad visual basada en el verde y naranja oficiales de kölbi.

Al entrar se puede elegir entre cuatro modos:

- **Neon Run:** atrapa los objetos de energía y evita obstáculos durante 25 segundos.
- **Pulso de señal:** toca cuando el indicador atraviesa la zona verde; la señal se acelera en cada nivel.
- **Eco kölbi:** observa y repite una secuencia de tonos y luces que crece en cada ronda.
- **Ruta de cobertura:** conecta una ruta de nodos del color objetivo sin equivocarte.

Los cuatro modos comparten puntos, racha, vidas y niveles. El logo oficial local está en `assets/kolbi-logo-original.svg` y se usa en la cabecera y el escenario ilustrado `assets/activation-stage.svg`.
